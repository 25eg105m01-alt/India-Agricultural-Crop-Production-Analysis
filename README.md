# India's Agricultural Crop Production Analysis

## Project Overview

This project analyzes India's agricultural crop production data to identify trends, regional variations, and patterns in crop production.

## Objective

The main objective is to use data analysis and Tableau visualizations to understand agricultural production trends and support better decision-making.

## Scenarios

### Scenario 1: Small-Scale Farmer

Identify suitable crops and understand seasonal and regional production trends to help farmers make better farming decisions.

### Scenario 2: Government Policy Analyst

Identify low-yield regions and analyze long-term agricultural production patterns to support data-driven policy decisions.

### Scenario 3: Agribusiness Investor

Identify high-growth crops and regions to support informed investment decisions in the agricultural sector.

## Data Collection and Extraction

The agricultural crop production dataset is collected and analyzed to understand crop production across different regions and years.

## Data Preparation

The data is prepared for analysis by checking the data, handling missing or inconsistent values, and organizing the required fields.

## Data Visualization

Tableau is used to create visualizations showing crop production trends, regional distribution, and changes in agricultural production over time.

## Dashboard

An interactive Tableau dashboard is created to present the analysis and allow users to explore agricultural production patterns.

## Tools Used

- Tableau
- Data Analysis
- Data Visualization
- Data Preparation

## Conclusion

This project provides insights into India's agricultural crop production and demonstrates how data visualization can support better, data-driven decisions.
